# SafeDrive AI 

## Overview
SafeDrive AI predicts driving risk based on speed and time,wheather.

## Problem
Unsafe speed leads to accidents.

## Solution
This system classifies risk into Low, Medium, High.

## Features
- Risk prediction
- Simple UI
- AI-based logic

## RL Concept
- State: speed, time
- Action: accelerate / slow
- Reward: safe driving = positive

## Tech Stack
Python

## How to Run
1. pip install -r requirements.txt
2. python app.py
